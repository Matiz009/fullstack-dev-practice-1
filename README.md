# Full-Stack Dev Practice (Part 1)

Practice work from a full-stack web development course.

## What's inside

| Folder | Contents |
|---|---|
| `index.html`, `second.html`, `styles/` | HTML/CSS pages |
| `Bootstrap/`, `MaterialUI/` | UI frameworks |
| `Advanced JS/` | ES6 classes (Shape, Circle, Square), sync vs async |
| `node/` | Node.js basics |
| `Backend/` | Express + Mongoose todo/task API (`/todos`, `/create-todo`, `/tasks/:id`) |

## Running the backend

Requires MongoDB running locally (`mongodb://localhost/todos`).

```bash
cd Backend
npm install
node index.js
```
